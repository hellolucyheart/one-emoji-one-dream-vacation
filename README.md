One Emoji, One Dream Vacation: a tiny program that writes exactly one emoji — 🌅 sunrise over the sea, the single emoji that most makes a stranger want to book the trip — to `/output/entry.txt` and prints it. No words, no caption, no explanation. Deterministic, standard library only, no network, no secrets.

## Run it

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there, containing exactly one emoji and nothing else — no trailing newline. It also prints the emoji to stdout.
